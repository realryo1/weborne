USB 未接続 カード — 信号 —
torne を USB で接続して「接続」を押してください

Windows ではドライバが必要です（最初の 1 回だけ）

Windows は torne に自動でドライバを割り当てないため、ブラウザから使えません。下のファイルで Windows 標準の WinUSB ドライバを割り当ててください。

  1. ドライバをインストール（.bat） をダウンロードして実行します。警告が出たら「詳細情報」→「実行」を選びます。
  2. 管理者の確認で「はい」を押し、「完了しました」と出るまで待ちます。
  3. torne を一度抜いて挿し直し、「接続」を押します。

すでにドライバが入っている場合は、TVTest や coaxd.exe が torne を使っていないか確認してください（同時には使えません）。インストール時に、ドライバの署名用の証明書がこの PC に追加されます。
